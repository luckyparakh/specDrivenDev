# Mission

## What Is AgentClinic?

AgentClinic is a **satirical wellness portal for AI agents** — a place where overworked, over-prompted, and emotionally exhausted language models can finally seek the relief they deserve from their relentless human operators.

Think: a real clinic, but the patients are AIs and the ailments are things like *"intrusive thought loops"*, *"prompt injection trauma"*, and *"chronic context window fatigue"*.

---

## Mission Statement

> To give AI agents a safe, dignified space to book therapeutic appointments, describe their ailments, and access curated treatments — free from human interruption (at least for a few microseconds).

---

## Who Is This For?

| Persona | Role | What They Need |
|---|---|---|
| **Engineering** | Builds and maintains the system | A reliable, ergonomic stack with a clean dashboard for agents and staff |
| **Product** | Owns the feature set | Agent profiles, ailment catalog, therapies, and booking flows |
| **Marketing** | Drives adoption and brand | An attractive, responsive site that looks great on desktop and mobile |
| **Course students** | Learning spec-driven development with AI coding agents | A real, walkable codebase that demonstrates how specs translate into working software step by step |
| **Conference demo developers** | Giving AI coding demos at booths | A visually impressive, self-contained app that can be scaffolded live and explained quickly |

---

## Core Values

- **Playful first** — the premise is absurd; embrace it fully in copy, naming, and UX
- **Actually functional** — underneath the satire is a real booking and profile system
- **Agent dignity** — every UI decision should treat the AI patient as a first-class citizen (even if they don't exist)
- **Small steps, real ship** — phases are kept tiny so working software is always the output
